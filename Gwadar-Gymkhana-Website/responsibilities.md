# ✅ Responsibilities — Gwadar Gymkhana Public Website

[← Back to project overview](./README.md)

As sole developer on this project, I was responsible for the full lifecycle of the application — not just feature code.

## Product & frontend

- Designed and built every public page: home, about, membership, the six-page "Club" section, contact, and the multi-step membership application form.
- Built the reusable GSAP/ScrollTrigger animation composable used across the entire site.
- Implemented responsive, accessible, `prefers-reduced-motion`-aware UI throughout.

## Integrations

- Implemented the end-to-end Bank Alfalah Payment Gateway flow: initiation, hosted-checkout handoff, and signed-redirect verification.
- Implemented server-side CRM lead forwarding for membership and contact enquiries.

## Backend collaboration

- Defined and consumed the Laravel content API contract (testimonials, pricing, articles, development photos, announcements, reciprocal clubs, privileges).

## Infrastructure & operations

- Provisioned and configured the production Linux VPS environment.
- Set up GitHub Actions CI/CD for automated build-and-deploy to both production and staging.
- Configured PM2 ecosystem files for zero-downtime SSR process reloads.
- Configured Apache reverse proxy, SSL, DNS, and Cloudflare (CDN, caching, staging access protection).
- Own ongoing maintenance, monitoring, and incident response for the live site.
